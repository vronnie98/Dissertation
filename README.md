# Detecting AI-Generated Disinformation in Money Mule Recruitment

A machine-learning study for detecting scam and AI-generated recruitment adverts.

MSc dissertation project — Department of Security and Crime Science, University College London.
Author: Veronica Oprisan · Supervisor: Dr Nilufer Tuptuk

## Background

"Money mules" are people who let their bank accounts be used to move criminal money, often
after being deceived by fake job adverts. Criminals increasingly use AI to write these adverts,
producing fluent, professional-looking recruitment text at scale — which removes a signal that
previously aided detection, since such adverts used to be recognisable by poor wording.

This project develops and tests machine-learning models that detect scam and AI-generated
recruitment text, and examines the linguistic features that separate them. The aim is to
provide detection methods useful to online platforms and law enforcement. The work is purely
computational and does not involve recruiting, contacting, or interacting with any people.

## Research questions

1. **RQ1** — Can models reliably separate scam/recruitment adverts from legitimate ones?
2. **RQ2** — Can models distinguish AI-written from human-written recruitment text, and do
   these signals survive paraphrasing and transfer to an unseen AI model?
3. **RQ3** — Which linguistic features drive detection?

## Data

The study uses three open or researcher-generated data sources, none involving participant interaction:

1. **EMSCAD** (Employment Scam Aegean Dataset) — a public dataset of real job adverts labelled
   legitimate or fraudulent (Vidros et al., 2017). Published in 2017, its adverts predate widely
   available generative AI and serve as confidently human-written examples.
2. **Synthetic recruitment adverts** — generated by the researcher using several AI language
   models, including an adversarial "make this read as human" condition.
3. **Reddit posts** — a sample of publicly available posts manually collected from subreddits
   discussing job scams, used as an unlabelled external test set (anonymised at collection).

The datasets are **not** included in this repository. EMSCAD can be downloaded from Kaggle
("Real / Fake Job Posting Prediction").

## Current progress

This repository currently contains the baseline pipeline for **RQ1** (scam vs. legitimate detection):

- Merges the text fields (company profile, description, requirements, benefits) of each advert.
- Encodes each advert into a sentence embedding using `all-MiniLM-L6-v2` (Sentence Transformers).
- Trains a Random Forest classifier on the embeddings and evaluates it on a held-out test set.

Because the dataset is highly imbalanced (roughly 95% legitimate, 5% fraudulent), evaluation
looks beyond overall accuracy to how well the model identifies the minority (fraudulent) class.

## Repository contents

## How to run

1. Install the dependencies:
   ```
   pip install sentence-transformers scikit-learn pandas numpy
   ```
2. Download the EMSCAD dataset from Kaggle and place the CSV in the project folder.
3. Open `Classifier.ipynb` and run the cells in order.

The notebook downloads the `all-MiniLM-L6-v2` model on first run and saves the generated
embeddings locally so they do not need to be recomputed on subsequent runs.
